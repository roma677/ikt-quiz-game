# Quiz Arena 2.0

200 вопросов, 10 лекций, выбор количества, индивидуальный и командный режимы. По умолчанию все лекции, 20 вопросов, 20 секунд, случайная выборка. Ответы перемешиваются всегда.

## Обновление
Замените server.js, package.json и public/index.html; добавьте questions.json в корень. Render: npm install / npm start. Дождитесь успешного развёртывания.

## Локально
npm install, npm start, http://localhost:3000.

Комнаты и результаты хранятся в памяти; перезапуск их сбрасывает.
