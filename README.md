# ИКТ Quiz Arena — многопользовательская версия

## Что умеет
- Ведущий создаёт комнату; сервер выдаёт новый случайный PIN из 6 цифр.
- Участники заходят с телефонов/компьютеров по PIN и имени.
- Автоматическое распределение по командам (2–6 команд).
- 15 вопросов по PDF «Лекция №1. Введение в ИКТ».
- 20 секунд на ответ, ответы синхронизируются сервером.
- Баллы за правильность и скорость, рейтинг игроков и команд.

## Запуск на компьютере
1. Установите Node.js 18 или новее: https://nodejs.org/
2. Распакуйте архив.
3. Откройте терминал в папке проекта.
4. Выполните `npm install`
5. Выполните `npm start`
6. На компьютере ведущего откройте `http://localhost:3000`.

## Подключение телефонов в одной Wi-Fi сети
Узнайте локальный IP компьютера ведущего (например, 192.168.1.25).
Участники открывают `http://192.168.1.25:3000` на своих устройствах.
Компьютер и телефоны должны быть в одной сети; разрешите Node.js доступ в брандмауэре.

## Доступ из разных сетей / через интернет
Нужно разместить проект на хостинге, поддерживающем Node.js и WebSocket (например, Render или Railway).
Загрузите содержимое архива в GitHub-репозиторий и создайте Web Service из этого репозитория.
Команда запуска: `npm start`. После публикации все участники заходят по одному публичному URL.
Не используйте статический хостинг, который не поддерживает сервер Node.js/WebSocket.

## Важно
Комнаты и результаты хранятся в памяти сервера и исчезают после перезапуска приложения. Это учебный прототип для проведения викторины, без постоянных аккаунтов и базы данных.
